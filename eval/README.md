# Eval v0.1

Цель ADR-015: адекватный ответ на 20 базовых вопросов из загруженного текста
и отсутствие зацикливания/«шизы».

## Состав первого набора

- 20 вопросов по одному загруженному тексту (факты, определения, связи).
- 5 диалоговых сценариев на «рассказ о дне» и уточнения.
- Проверки-инварианты:
  - ответ содержит только узлы/связи из графа;
  - нет дословного повтора предыдущей реплики;
  - при низкой уверенности есть оговорка или честное «не знаю»;
  - волна активации не превышает `max_depth` и затухает;
  - личные данные одного пользователя не видны другому.
