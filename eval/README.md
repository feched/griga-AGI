# Eval v0.1

Цель ADR-015: адекватный ответ на 20 базовых вопросов из загруженного текста
и отсутствие зацикливания/«шизы».

## Запуск

```powershell
.\.venv\Scripts\python.exe -m scripts.run_eval
.\.venv\Scripts\python.exe -m scripts.run_eval --json
```

Прогон работает в памяти процесса и не трогает PostgreSQL. Код возврата
`0` — все кейсы прошли, `1` — есть провалы.

## Состав набора

- [`corpus.txt`](corpus.txt) — 18 фактов, которые пишутся в граф.
- [`questions.json`](questions.json) — 20 вопросов с ожиданиями.
- [`../tests/test_eval.py`](../tests/test_eval.py) — тесты раннера.

Формат кейса:

```json
{
  "id": "q01",
  "question": "Что такое трава?",
  "intent": "ответить_прямо",
  "contains": ["растение"],
  "allow_fallback": false
}
```

- `intent` — ожидаемое намерение (необязательно);
- `contains` — слова, которые обязаны быть в ответе с учётом склонения;
- `allow_fallback` — разрешён ли fallback (по умолчанию нет).

## Проверки-инварианты

- ответ не пустой и не `fallback` без разрешения;
- намерение совпадает с ожидаемым;
- ответ содержит ожидаемые слова (с учётом падежей);
- ответ не повторяет предыдущую реплику;
- активация в рабочей памяти не превышает `activation.clamp`.
