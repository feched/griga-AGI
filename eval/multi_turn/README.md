# Многоходовые сценарии (M11)

Цель — проверить, что Гриша удерживает контекст диалога, а не отвечает
как калькулятор на один запрос.

## Запуск

```powershell
# все сценарии
.\.venv\Scripts\python.exe -m scripts.run_multi_turn

# только один сценарий
.\.venv\Scripts\python.exe -m scripts.run_multi_turn --only scenario_4

# машинный отчёт
.\.venv\Scripts\python.exe -m scripts.run_multi_turn --json
```

Каждый сценарий выполняется на **чистом** графе в памяти
(`KnowledgeGraph` + `MemoryStorage`), поэтому сценарии не влияют друг на
друга и не требуют PostgreSQL. Код возврата `0` — всё прошло, `1` — есть
провалы.

## Формат сценария

```json
{
  "id": "scenario_1_intro",
  "description": "Знакомство и личные факты",
  "turns": [
    {
      "user": "Привет, меня зовут Саша.",
      "expected_intent": "greet",
      "expected_contains": ["Саша"],
      "note": "приветствие должно заодно вернуть имя"
    }
  ],
  "invariants": [
    {
      "source": "трава",
      "relation": "has_property",
      "target": "синяя",
      "present": false
    }
  ]
}
```

- `expected_intent` — алиас или нативное значение `Intent`:
  `greet` → `поздороваться`, `statement` → `запомнить_факт`,
  `answer` → `ответить_прямо` / `ответить_с_оговоркой`,
  `dont_know` → `признать_незнание`, `clarify` → `уточнить`.
- `expected_contains` — слова, которые обязаны быть в ответе (с учётом
  склонения: «Москве» ≈ «Москва»).
- `invariants` — состояние графа **после** сценария. Текстовые проверки
  не видят устаревшее ребро («сказал нет, а связь осталась»), инварианты
  видят. Погашенное ребро (`metadata.status = "negated"`) для проверки
  `present: false` считается отсутствующим.
- `note` — подсказка для человека, на проверки не влияет.

## Что уже проверяется

| Сценарий | Идея |
|---|---|
| `scenario_1_intro` | имя и личные факты, вопрос о них через 5+ реплик |
| `scenario_2_properties` | два свойства, повторный вопрос без дословного повтора |
| `scenario_3_unknown` | незнание → новый факт → правильный ответ |
| `scenario_4_correction` | «Нет, трава зелёная» гасит старый цвет (`status=negated`) |
| `scenario_5_story` | мини-история из трёх фактов и вывод по ним |

## Что считается провалом

- пустой ответ или `fallback`;
- неверное намерение;
- в ответе нет ожидаемого слова;
- ответ дословно повторяет предыдущую реплику;
- инвариант графа не выполнен.
