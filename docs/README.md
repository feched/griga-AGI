# Документация Griga AGI v0.1

Этот каталог — источник истины по архитектуре v0.1.

| Документ | Что внутри |
|---|---|
| [`Home.md`](Home.md) | Obsidian-стартовая страница и карта документов |
| [`VISION.md`](VISION.md) | Проблема, пользователи, сценарии, AGI-критерии, non-goals, метрики |
| [`ARCHITECTURE.md`](ARCHITECTURE.md) | Парадигма, граф, активация, обучение, генерация, память, safety shell |
| [`GLOSSARY.md`](GLOSSARY.md) | Термины проекта |

Каталог `docs/` открывается как **Obsidian-vault** (папка, а не копия):
человек и агент редактируют одни и те же файлы. Служебная `.obsidian/`
в git не попадает.

## Статус документов

- `VISION.md`, `ARCHITECTURE.md`, `GLOSSARY.md` — draft, версия парадигмы 0.1.
- ADR-001–006, 008–010, 014, 015 — accepted.
- ADR-007 в исходном наборе отсутствует.
- ADR-011 (лицензия), ADR-012 (один агент с ролями),
  ADR-013 (причинность и заземление) — TBD.

## Правило

Если код и документ расходятся — прав документ; код приводится к нему.
Изменение парадигмы оформляется новым ADR, а не правкой кода «по месту».
