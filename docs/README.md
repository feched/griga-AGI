## Статус документов

- `VISION.md`, `ARCHITECTURE.md`, `GLOSSARY.md` — draft, версия парадигмы 0.1.
- ADR-001–006, 008, 009, 014, 015 — accepted.
- ADR-007 в исходном наборе отсутствует.
- ADR-010 (safety-пороги), ADR-011 (лицензия), ADR-012 (один агент с ролями),
  ADR-013 (причинность и заземление) — TBD.
- `ADR-009` — незавершённый черновик: схема конструкции обрывается на JSON.

## Правило

Если код и документ расходятся — прав документ; код приводится к нему.
Изменение парадигмы оформляется новым ADR, а не правкой кода «по месту».
