# ADR-015: Scope v0.1 (Границы первой версии)

**Статус:** accepted
**Дата:** 23.11.2026
**Связанные доки:** VISION.md, ARCHITECTURE.md

## Контекст

Чтобы не утонуть в функциях, нужно четко определить, что входит в v0.1.

## Решение

### Что входит в v0.1:
1. **Один пользователь:** Локальный CLI-интерфейс.
2. **Только русский язык:** (Архитектура языко-независима, но модель парсера — русская).
3. **Локальная БД:** **PostgreSQL** (строго).
4. **Память:** Общий граф + один Личный подграф (с разделением на уровне БД).
5. **Визуализатор:** Веб-страница на D3.js (или Python networkx), отображающая текущий активный граф (для отладки волны).
6. **Умения:** Поддержка диалога (рассказ о дне), ответы на фактические вопросы из графа.
7. **Никакой автоматизации:** Без веб-поиска, без исполнения кода, без самоизменения кода.

### Метрики v0.1:
- 20-30 конструкций в банке.
- 100% отсутствие «зацикливания» и «шизы» (благодаря clamp и fan-effect).
- Адекватный ответ на 20 базовых вопросов из загруженного текста.
