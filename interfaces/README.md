# Интерфейсы Griga AGI

Здесь лежат точки входа для человека. Сам граф живёт в PostgreSQL
(`griga_v01`), а не в файле: интерфейс подключается к нему и показывает
только то, что доступно пользователю.

## CLI-оболочка (agent style)

```powershell
# из корня репозитория
.\.venv\Scripts\python.exe -m griga.interfaces.agent

# от имени пользователя
.\.venv\Scripts\python.exe -m griga.interfaces.agent --user "Алиса"
```

Или двойной клик по ярлыку **Griga CLI** на рабочем столе (создаётся
`create-shortcuts.ps1`).

Команды:

| Команда | Что делает |
|---|---|
| `/help` | список команд |
| `/status` | узлы, рёбра, ходы, последнее намерение |
| `/history 20` | последние события audit-log |
| `/graph` | D3-визуализатор активного графа |
| `/export [путь]` | снимок графа в JSON (по умолчанию `interfaces/graph_snapshot.json`) |
| `/user Алиса` | переключить личный подграф |
| `/verbose off` | скрыть строку трассировки |
| `/clear` | очистить экран |
| `/quit` | выход |

Обычный текст уходит в диалог: факты пишутся в граф, вопросы получают
ответ из графа. Строка под ответом показывает намерение, конструкцию и
число попыток — как трасса агента.

## Граф

- Долговременный граф — PostgreSQL, таблицы `users / nodes / edges / graph_events`.
- Снимок для отладки — `/export` или `scripts/demo_visualize.py`.
- Визуализатор — `/graph` (локально, `127.0.0.1:8765`, без интернета).

`graph_snapshot.json` не коммитится: в нём могут быть личные факты.

## Файлы

- `start-cli.ps1` — запуск оболочки (проверяет `.venv` и `.env`).
- `start-cli.cmd` — двойной клик для Windows.
- `create-shortcuts.ps1` — ярлыки «Griga CLI» и «Griga Docs» на рабочем столе.
